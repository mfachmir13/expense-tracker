/** * ============================================================ * BACKEND CLOUD SYNC — Expense Tracker * Ditempel di: Google Sheets > Extensions > Apps Script * ============================================================ * Cara pakai: * 1. Buka Google Sheets baru (kosong, bebas namanya). * 2. Extensions > Apps Script. * 3. Hapus semua isi editor, ganti dengan seluruh isi file ini. * 4. Ganti nilai TOKEN di bawah dengan teks rahasia bebas * (anggap seperti password) — JANGAN bagikan ke orang lain. * 5. Klik Deploy > New deployment. * - Klik ikon gerigi di "Select type" > pilih "Web app". * - Description: bebas (misal "expense-tracker-sync"). * - Execute as: Me (akun Google kamu). * - Who has access: Anyone. * - Klik Deploy. Mungkin diminta "Authorize access" — izinkan. * 6. Copy "Web app URL" yang muncul (diakhiri /exec). * URL ini + TOKEN di atas yang diisi ke aplikasi (Settings > Sinkronisasi Cloud). * 7. Kalau nanti kode ini diedit lagi, ingat untuk "New deployment" * lagi (atau "Manage deployments" > Edit > New version) supaya * perubahan kepakai di URL yang sama. * ============================================================ */ // 🔑 GANTI INI dengan token rahasia buatanmu sendiri (bebas, makin acak makin aman) const TOKEN = 'GANTI_DENGAN_TOKEN_RAHASIA_KAMU'; const SHEET_NAME = 'Data'; const COLLECTIONS = ['transactions', 'rekening', 'categories', 'incomeCategories', 'goals']; function getSheet_() { const ss = SpreadsheetApp.getActiveSpreadsheet(); let sh = ss.getSheetByName(SHEET_NAME); if (!sh) { sh = ss.insertSheet(SHEET_NAME); sh.appendRow(['key', 'value']); const defaults = { transactions: [], rekening: [], categories: [], incomeCategories: [], budgets: {}, goals: [] }; Object.keys(defaults).forEach(function (k) { sh.appendRow([k, JSON.stringify(defaults[k])]); }); } return sh; } function readCollection_(sh, key) { const data = sh.getDataRange().getValues(); for (let i = 1; i < data.length; i++) { if (data[i][0] === key) { const def = key === 'budgets' ? '{}' : '[]'; return { row: i + 1, value: JSON.parse(data[i][1] || def) }; } } // Baris belum ada -> buat baru const def = key === 'budgets' ? {} : []; sh.appendRow([key, JSON.stringify(def)]); return { row: sh.getLastRow(), value: def }; } function writeCollection_(sh, row, value) { sh.getRange(row, 2).setValue(JSON.stringify(value)); } function jsonOut_(obj) { return ContentService .createTextOutput(JSON.stringify(obj)) .setMimeType(ContentService.MimeType.JSON); } function doGet(e) { const lock = LockService.getScriptLock(); try { lock.waitLock(15000); // tunggu maksimal 15 detik kalau ada request lain lagi diproses } catch (err) { return jsonOut_({ ok: false, error: 'Server sibuk, coba lagi sebentar lagi' }); } try { const p = e.parameter; if (p.token !== TOKEN) { return jsonOut_({ ok: false, error: 'Token salah' }); } const sh = getSheet_(); const action = p.action; // ── AMBIL SEMUA DATA ── if (action === 'getAll') { const out = {}; COLLECTIONS.concat(['budgets']).forEach(function (k) { out[k] = readCollection_(sh, k).value; }); return jsonOut_({ ok: true, data: out, serverTime: new Date().toISOString() }); } // ── BUDGET (objek key-value per catId, bukan array) ── if (action === 'setBudget') { const item = JSON.parse(p.item); const rc = readCollection_(sh, 'budgets'); if (item.amount > 0) rc.value[item.catId] = item.amount; else delete rc.value[item.catId]; writeCollection_(sh, rc.row, rc.value); return jsonOut_({ ok: true }); } // ── MIGRASI: timpa SEMUA koleksi cloud sekaligus dari data lokal ── if (action === 'seedAll') { const data = JSON.parse(p.data); const keys = COLLECTIONS.concat(['budgets']); keys.forEach(function (k) { const rc = readCollection_(sh, k); const val = (data[k] !== undefined) ? data[k] : (k === 'budgets' ? {} : []); writeCollection_(sh, rc.row, val); }); return jsonOut_({ ok: true }); } // ── CRUD UNTUK KOLEKSI BERBASIS ARRAY (by id) ── const collection = p.collection; if (COLLECTIONS.indexOf(collection) === -1) { return jsonOut_({ ok: false, error: 'Koleksi tidak dikenal: ' + collection }); } const rc = readCollection_(sh, collection); const list = rc.value; if (action === 'add') { const item = JSON.parse(p.item); list.push(item); writeCollection_(sh, rc.row, list); return jsonOut_({ ok: true, item: item }); } if (action === 'addMany') { const items = JSON.parse(p.items); items.forEach(function (it) { list.push(it); }); writeCollection_(sh, rc.row, list); return jsonOut_({ ok: true, count: items.length }); } if (action === 'update') { const item = JSON.parse(p.item); const idx = list.findIndex(function (x) { return x.id === item.id; }); if (idx === -1) return jsonOut_({ ok: false, error: 'Data dengan id tersebut tidak ditemukan' }); list[idx] = item; writeCollection_(sh, rc.row, list); return jsonOut_({ ok: true, item: item }); } if (action === 'delete') { const id = p.id; const idx = list.findIndex(function (x) { return x.id === id; }); if (idx === -1) return jsonOut_({ ok: false, error: 'Data dengan id tersebut tidak ditemukan' }); list.splice(idx, 1); writeCollection_(sh, rc.row, list); return jsonOut_({ ok: true }); } if (action === 'deleteMany') { const ids = JSON.parse(p.ids); const idSet = {}; ids.forEach(function (id) { idSet[id] = true; }); const filtered = list.filter(function (x) { return !idSet[x.id]; }); writeCollection_(sh, rc.row, filtered); return jsonOut_({ ok: true, deleted: list.length - filtered.length }); } return jsonOut_({ ok: false, error: 'Aksi tidak dikenal: ' + action }); } catch (err) { return jsonOut_({ ok: false, error: String(err) }); } finally { lock.releaseLock(); } }
